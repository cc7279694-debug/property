# 砺石V1个人体验清单

供你以后集中试用，不要求现在安装或操作。本轮只完成桌面检查与候选准备，以下手机流程均未实际执行，不代表PASS。

**仅供个人试用，建议使用可丢弃数据。不要把尚未完成实际恢复验证的版本作为重要数据的唯一副本。**若体验账本已有重要记录，跳过覆盖恢复练习，不要清除App数据来“准备测试”。

## 现在

- 新建一个普通合成长期项目，查看开始日期、持有天数、净投入和日均成本；追加一笔投入与一笔收回，核对详情和首页更新。
- 编辑名称/类别，返回未保存表单时核对提示；区分“结束记录”和“删除记录”。已结束项目不再增长持有天数，但真实后续结算仍会影响净投入。
- 新建合成订阅，手动确认一笔测试续费，分别核对付款日、生效日与覆盖边界；真实使用只记录已发生的付款，不要把未来预付当成已使用。
- 查看暂停、恢复、停止与当前状态。停止App中的记录不会取消服务商扣费；不要为了试用去修改任何真实服务商订阅。

## 回看

- 名称搜索的实际入口在“现在”首页。搜索项目与订阅，进入详情后检查能返回同一搜索结果；返回时原查询不应意外丢失。
- 从“回看”进入长期项目历史和订阅历史；暂停、到期未停止和未来停止不应提前归入已停止历史。
- 查看长期复盘、项目/订阅成本图、总成本趋势、类别分析和年度回顾。区分当前日均、历史平均、折算付费时长与真实付款年份。
- 从类别分析或历史进入具体记录，再返回原来源。空记录、真正0元、负净投入、加载与读取失败应能分辨；遇到错误先保留提示，不要反复保存。

## 设置

- 在各自体系中新建、改名或合并合成类别；长期项目和订阅类别互相独立。合并前先看影响范围。
- 打开成本计算说明；关于页面应读取当前安装版本：`0.1.0-preview.2-debug`、Code18，名称“砺石·体验版”，明确为个人体验/可调试构建，不是正式Release。
- 查看续费与里程碑提醒偏好、系统权限提示；提醒不保证厂商后台准点送达。
- 仅在确认全部记录可丢弃的账本上，手动导出完整备份，区分成功、取消、失败与结果未知。文件未加密，请自行妥善保管。
- 若选择练习恢复：先核对所选备份与当前记录摘要，再明确确认。恢复是完整覆盖，不是合并，可能替换项目、订阅、图片和设置；取消和失败提示需仔细看。
- 结果未知时不要清数据、重复覆盖或删除文件；保留提示再反馈。无法完整核验图片时，不应跳过图片而显示完整备份成功。

## 使用与反馈边界

只自行选择安装名为“砺石·体验版”、包名`com.cooper.lithic.preview.debug`的候选；不要用研发Debug或M22验证包代替。若旧体验版升级显示签名冲突，先停止，不卸载旧应用来绕过。安装、升级及真实手机行为本轮均NOT_RUN。

记录遇到的问题时，描述入口、操作和页面提示即可；不要公开个人账本、未加密备份或私人通知截图。M10图片安全、M20平台提醒、M22完整旅程/长历史/IME及正式签名与发行门禁仍有未完成项，详见[P04交付报告](LITHIC-P04-Integration-Delivery.md)。
