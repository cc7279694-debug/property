# Preview 10 个人体验说明

适用于 C8 交付报告核验的 **Preview 10 / code26**，包名 `com.cooper.lithic.preview.debug`。这是可调试的个人体验版，不是正式 V1.0。本清单供你自行选择时间体验，不要求现在安装或操作手机。

**建议先用可丢弃的试用记录。不要把该版本作为重要记录的唯一副本。**

## 安装前

- 核对交付报告里的 APK 路径、版本、SHA-256 和证书摘要，只使用“砺石·体验版”。不要用普通研发 Debug、M22 或 C3 验证包替代。
- 已有体验记录时，先保留原应用与数据，手动导出完整备份并确认成功，再选择同包、同证书的覆盖更新。真实升级仍未验证。
- 若安装失败或提示签名冲突，保留原应用及错误提示，停止安装；不要通过卸载、清除数据或换包名绕过。本轮没有自动安装或手机操作。

## 现在：物品与订阅

- 从右下角＋新建一件试用物品，核对名称、类别、开始拥有日期、初始投入和实际付款日。保存后进入详情，返回应回到原来的首页；从列表新增时应回到列表。
- 在详情“记一笔”中追加投入、记收回；维修款可用投入和说明记录。核对净投入、持有天数、日均成本及首页刷新，区分真实 0 元、负值和“尚未取得”。
- 用可丢弃物品体验以旧换新：先看金额与关联事实预览，再确认；非现金折抵应有标识。不要把联动交易当成可单独改动的普通金额。
- 区分结束持有与永久删除。结束后去历史查看原记录、成本和金额记录；不要为了体验删除重要记录。
- 用可丢弃的试用记录检查订阅付款录入，分别核对付款日、生效日、到期边界和周期；记录真实订阅时只确认已经发生的付款。当前套餐价格、历史平均成本、折算付费时长应各自清楚；未来预付不应显示为已经使用。
- 查看暂停、恢复、停止及历史。应用只记录你确认的付款，不会自动新增续费；暂停或停止砺石记录不会取消服务商扣费。真实服务商订阅请另行管理。

## 回看：找记录、看变化

- 搜索入口在“现在”顶部。搜索物品或订阅，进入详情再返回，检查查询和来源是否保持；从历史或类别分析进入时也应返回原入口。
- 查看物品、订阅和总成本趋势，切换日期并核对准确金额、单位、项目与订阅贡献。不要把当前日均成本当成今天扣款或全部生活消费。
- 查看类别、年度与长期复盘；无记录不应画假曲线，加载、读取失败和保留旧结果应能区分。再次进入回看时，观察金额、日期与曲线是否稳定。

## 设置、字体与错误反馈

- 查看计算说明和关于：安装后应显示真实的 `0.1.0-preview.10-debug`、code26 和个人体验状态。
- 按平时使用的明暗主题和系统字体查看标题、金额、列表、表单与底部按钮；大字体下应可滚动，关键金额、错误和保存操作不应被遮挡。无需修改屏幕密度来“适配”。
- 留意返回未保存表单的提示，以及空字段、非法金额等明确错误。输入应保留；若提示写入结果未确认，按页面的核对入口处理，不另建记录或反复付款。
- 备份是手动导出的，文件未加密，请妥善保存。恢复是**完整覆盖，不是合并**，可能替换物品、订阅、图片和设置；只在全部记录可丢弃时练习，并先核对预览。已有重要体验记录时跳过恢复练习。
- 若备份、恢复或保存显示结果未知，保留现场和提示再反馈，不清除应用数据，也不重复覆盖。提醒仍受系统权限和厂商后台限制，不保证准点送达。

## 尚未关闭的边界

- 图片仅支持已有、登记且校验通过封面的只读显示；本版未开放新增、替换或移除封面。没有封面与“封面暂不可用”是不同状态，不能据此认定业务记录丢失。
- C7 未运行的 Android 测试继续为 **NOT_RUN**；用户体验不能替代自动化安全测试。真实视觉、动态、字体/IME、性能及升级仍待验证。
- 图片导入 **MEDIA_IMPORT_BLOCKED**，M10 JPEG、M20 提醒平台、M22、C3、M13 及 G1～G4 等历史未完成门禁均未关闭；本清单不表示通过发行验收。
- 反馈时写清入口、操作、预期和实际提示即可；如需截图，先遮挡私人内容，不发送个人账本、未加密备份、账号或通知信息。
