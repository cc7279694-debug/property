7. Recommendation and limits

Use public PreferenceDataStoreFactory.create(storage=OkioStorage(FileSystem.SYSTEM, PreferencesSerializer, producePath=...), scope=...). Keep the same Preferences protobuf bytes, extension, key, controller, MAIN process gate, no-backup path, single-instance guard, and corruption failures. Do not use the misleading createWithPath shortcut or move frozen business stores. Do not delete an existing target before replacement. The unchanged second-write/reopen assertion must pass using real files, and final build/Lint must confirm app classpath/API legality. Android filesystem/latency/process verification remains NOT_RUN.

API availability was inspected from cached binaries; presence in cache alone is not a Gradle compile/runtime dependency-resolution proof. Final target compilation is the required confirmation.
