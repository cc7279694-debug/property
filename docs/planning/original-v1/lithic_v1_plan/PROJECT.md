# 项目身份与边界

## 目标
一款纯本地 Android APK，记录长期项目和固定周期订阅，回答“哪些东西陪伴得久”和“已录入且当前有效的项目日均成本合计是多少”。

## 固定边界
不登录、不接服务器、不接 Supabase/Vercel、不做传统记账、投资、AI、估值、预测、成本目标、价值评分或使用打卡。
只记录人民币。长期项目包括实物和数字买断；订阅仅月付、季付、年付。
原 WHOCARE 保留，不复制其账户、股票、量化、云同步和后台逻辑。

## 工程身份（本轮建议，M01 落地）
工作名：砺石 LITHIC。新工程名：lithic-android。生产 applicationId：com.cooper.lithic；开发版追加 .debug。
包名在第一个承载真实数据的内部发布版之前冻结，不随展示名修改。

## 成功标准
不联网也能冷启动、录入、修改、结算、续费、暂停、恢复、查历史，并导出和恢复全部数据。
核心计算在列表、详情、首页、图表和年度回顾中一致。
不要求每天操作；付款不自动伪造；过期服务不继续进入当前日均成本。
长期升级和备份恢复不丢失项目、图片、关联或设置。

## 当前事实
本规划包不包含产品实现，也不证明任何测试已经通过。新仓库和 Android 工程尚未由本轮创建。
