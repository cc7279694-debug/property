# M03 订阅周期与状态引擎 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking. 本项目采用用户授权后Codex逐模块执行、独立验收；本文件本身不授权实施。

**Goal:** 统一30/90/365折算、真实覆盖、预付生效、暂停到期与历史平均。

**Architecture:** 单Android app module，Compose → ViewModel → Repository → Room/统一领域引擎。跨文件恢复按BACKUP_SPEC处理；页面不复制计算规则。

**Tech Stack:** Kotlin、Compose、Navigation 3、Room、DataStore；版本在M01真实验证锁定，后续不随意升级。

**Spec:** `docs/specs/PRODUCT_SPEC.md`、`docs/specs/DOMAIN_CONTRACT.md`、`docs/specs/ARCHITECTURE.md`；UI、备份、通知分别服从同目录专门规格。

## Global Constraints
Local-only、人民币、月30/季90/年365、手动真实确认付款、无估值/预测/评分/目标、无服务器/AI/旧Finance/Quant、单模块停步验收、无破坏性迁移。
所有任务表为未来验收标准，当前状态全部NOT_RUN。

## 测试案例与预期断言
| 编号 | 测试名 | 预期 |
|---|---|---|
| M03-T01 | `monthly_standard_rate` | 月付150元得5元/天，即使真实区间31天。 |
| M03-T02 | `annual_purchase_not_elapsed_year` | 刚预付3650元年费：折算365天、平均10元；生效当天实际已过去仅1天，无一年里程碑。 |
| M03-T03 | `prepaid_next_rate_does_not_start_early` | 1月20日付180元、2月1日生效；1月20日仍150/30=5，2月1日变6。 |
| M03-T04 | `expired_has_zero_current_rate` | [1月1日,2月1日)到2月1日无续费时当前贡献0。 |
| M03-T05 | `pause_does_not_erase_paid_history` | 暂停不改已付金额和已购标准天数，只截断当前有效贡献/实际经过时间。 |
| M03-T06 | `overlaps_rejected` | 同服务重叠区间拒绝，相邻区间允许；付费日未来拒绝。 |
