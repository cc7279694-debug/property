样稿的选择反馈采用 200ms 色彩过渡。页面转场、触感及系统减少动效行为仍是 Compose 实施时的验证项。底栏本稿用文字作为识别方式，对齐涛声 v0.4.0 实际样式。外壳采用近实色表面，保留三主题可读性与 Android 系统导航安全区。

使用 [浏览器验证脚本](verify-mockups.cjs)复查时，传入本机 `playwright-core` 模块路径和 Chromium 可执行文件路径。设置 `LITHIC_EXPORT_BOARDS=1` 可重新导出同名 PNG。样稿无需外部在线字体、图库或用户数据。素材信用链接仅在手动点击时跳转。
