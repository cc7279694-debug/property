# LITHIC V3 无障碍与响应式

V3-02 · 候选规则和后续验收口径。浏览器画板用于对照版式与内容，Android 原生交互、字体和对比度仍需单独验证。[高保真画板索引](HIGH_FIDELITY_SCREENS.md) · [设计系统](DESIGN_SYSTEM.md)

## 1. 紧凑屏与字体

| 场景 | 候选响应 | Android 验收 |
| --- | --- | --- |
| 320dp | 单列优先，窄条目封面可缩到 64×48dp。状态、日期和金额可换行，名称与金额都能读完。 | 查看两种记录、所有「全部」、新增和独立封面入口。确认无横向裁切、两个动作无命中重叠。 |
| 360dp | 标准高保真对照。档案从图位、名称和状态开始。保留页面边距与页末滚动余量，浏览器画板常规留出 20 CSS px。 | 比较三主题及 A/B 同数据顺序。检查键盘、系统栏、模态和最底部的完整信息。 |
| 400dp | 保留同一读序、实际字号和分区原则。空间多出时用于可读性与行内对齐。 | 复查长中文、中文英文混排、负金额、到期状态和宽屏差异。 |
| 横屏、分屏和较宽窗口 | 高度不足时让内容与大字滚动，保持底部动作可达。宽度增长后限制阅读行长，再评估双栏。 | 结合内容和导航区域、系统栏及折叠铰链。查看旋转、窗口缩放和从详情返回原列表。 |
| 150% 与 200% 系统字体 | 段落和操作区按内容增高，图标随布局重排。金额、单位和警告可逐块阅读，必要时将两个并排行拆成纵向。 | 真实系统设置取证。复查主按钮、返回、底栏、条目、金额符号和日期，覆盖窄宽及窗口矮化。 |

首页新增操作放在正文与三项底栏之间的测量区域。滚动区域在其上方结束，最后一条订阅及页尾说明可完全滑出。表单用相同占位原则处理底部提交与 IME，校验失败时焦点能到达第一个有问题的字段。系统状态栏、导航栏、显示缺口和 IME 安全区域由 Android Insets 提供。画板中的状态栏及手势线为视觉参考，键盘、刘海和真实 Insets 有待端侧核验。[P2-A1-R1 历史 200% 证据](../../evidence/LITHIC-UI-P2-A1-R1.md)

## 2. 触控、朗读和焦点

- 所有独立可操作目标至少 48×48dp，图标可用 20–24dp。以真实布局与坐标验证可分别触发，例如首页行打开记录、独立封面操作、两组「全部」、回看选日及提交。
- 条目按名称、记录类型、类别、状态、日期或时长、完整金额读取。完整金额语义合并人民币、符号、数值、单位及指标名称。根据选择状态朗读「现在／回看／设置」。装饰图标和用于说明相同内容的封面避免重复朗读。
- 表单焦点沿业务输入顺序走，日期、错误和提交结果可识别。读到只读核对时仍保留原对象和提交状态。新增、确认和恢复对话框先读标题与影响范围，再读安全退出及确认动作。关闭后回触发点或按既有导航回到合理目标。
- 趋势图用文本摘要及可访问日期选择替代必须拖动的操作。线型、文本和当前值共同说明各条序列，项目、订阅、总额可独立辨认。
- 系统 Back、预测 Back、应用返回键、切换底栏使用现有源路径与守卫。表单退出区分没有改动、仍有草稿、提交中、待核对、已提交但重读失败。覆盖恢复进入既有锁定状态时，可用动作与说明一致。
- 反馈可在真实操作状态变化时作礼貌播报。未知写入禁止被读成明确失败或安全重试，保留「核对」与可用的只读重查入口。恢复覆盖前读出作用范围和取消动作。

## 3. 对比度与非颜色提示

对设计系统候选值做不透明纯色抽样，使用相对亮度 sRGB 公式。以下比值只描述列中的配对。

| 抽样配对 | 岩白雾蓝 | 纯白 | 深色黑灰 |
| --- | --- | --- | --- |
| 正文 / 背景 | 11.73:1 | 17.93:1 | 16.88:1 |
| 辅助文字 / 背景 | 6.29:1 | 6.69:1 | 8.84:1 |
| 辅助文字 / 独立表面 | 6.81:1 | 6.24:1 | 7.86:1 |
| 主要动作文字 / 按钮底 | 6.04:1 | 15.72:1 | 14.91:1 |
| 弱分隔 / 背景 | 1.26:1 | 1.25:1 | 1.60:1 |

普通文字目标 4.5:1，大号文字与关键非文本边界目标 3:1。弱分隔可辅助排版。焦点、选中、错误和图表需具备独立的文字、边界或形态线索。验收覆盖透明叠层、按压/禁用、真实模态、图片相邻区域、图表线和零线。静态样本不能给 Android 页面或全部组合授予通过。

## 4. 状态和阅读检查

| 状态 | 应读到的区别 |
| --- | --- |
| 正常、有封面、无封面 | 两类记录的名称及成本语义完整。无图保留身份位置，错误仍可判断。 |
| 确认空账本 | 无任何项目或订阅，显示空状态和单一可见新增。 |
| 只有历史 | 当前无有效记录，保留已录入含历史数量及「回看」入口。 |
| 真实零值 | 以真实 ¥0.00 与日期表达。占位、未取得与零值可分辨。 |
| 读取失败 | 无可信数据时只显示缺值与真实可用的处理动作；有旧快照时明确上次日期与结果，分开处理预览与全账本重试。 |
| 未保存输入 | 继续编辑保留原输入，明确放弃才退出，且没有写入。 |
| 待核对写入 | 原事实身份与提交内容保持稳定，核对后方可继续；覆盖恢复与账本重读各走现有保护。 |
