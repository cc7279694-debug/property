## 已取得的证据

- **浏览器画板渲染** · Chrome 157.0.8103.40 载入全部 19 组、57 帧。核对画板名、帧数、素材加载与运行异常。57 帧的内容区均无横向溢出，底部操作区与内容及三导航的边界未相交，测得底部首个按钮高度均至少 48 CSS px。正常滚动仍可能在视口边缘截出下一条记录。
- **目视抽查与修正** · 对照了 A/B、三主题、320 大字、360 大字订阅区、写入保护和备份恢复。大字时封面下的名称和读数改为纵排，恢复预览与确认复用同一画面内容，只改变滚动位置。候选色值静态抽样与受限结论见[无障碍与响应式](ACCESSIBILITY_AND_RESPONSIVE.md)。
- **证据边界** · 浏览器 2× 仅为版式压力样本。Android 构建、安装、系统字体、TalkBack、触控实测、Insets、系统 Back、IME、真实 SAF/覆盖恢复与性能均为本轮 `NOT_RUN`。历史原生证据沿用原范围。数据、签名与正式 App 身份未发生变更。

## 请独立审查的三点

1. A 在常规字号下先识别物品，同时让总日均在首屏可见。判断大字或更长名称时是否仍容易找到总额。
2. 三主题的表面和前景差异是否足以建立品牌识别，确认相同功能和状态具有相同动作层级。
3. 读写未知、删除与完整覆盖的后果是否都能在提交前理解，以及适配时仍能到达安全离开动作。
