# 详情页无障碍与响应式

**DESIGN_REVIEW_ONLY — NOT_PRODUCTION_UI**

本轮画板用 360、400、720 CSS px 对照候选逻辑宽度，100% 和 200% 为浏览器字号模拟。Compose 的中文字体回退、系统非线性缩放、实际触控和朗读留待 Android 验证。已冻结的首页 200% 截图仅用作节奏参考。[首页历史证据](../../evidence/LITHIC-Home-Final-Polish-09-Retry.md)

## 尺寸与字号

| 宽度 | 100% 布局 | 200% 布局 |
| --- | --- | --- |
| 360dp | 单列纵读。项目照片在身份区内，日均紧随身份。短金额组可并排，列表金额贴近所属事实。 | 名称与状态可换行。金额分组按完整内容换成纵排，日期、金额和操作各自成行。资料、最后一笔及页尾说明可通过纵向滚动读完。 |
| 400dp | 多出的宽度给名称、日期和金额留余量。保留原分区和操作位置。 | 仍优先保证完整读数，金额及状态仅在实际测量宽度足够时同列。复查中文长名称、数字和日期混排。 |
| 720dp | 居中单列，正文候选上限 560dp，两侧至少 20dp。图位限制在身份区内，避免封面挤出首屏成本。 | 正文仍为同一纵向阅读顺序。先按照测量结果重排，控制行长。窗口高度下降时滚动，确认框及底部按钮按内容增高。 |

项目照片采用最大 240×180dp 的 4:3 图框，Fit 保留照片原比例。已有订阅封面使用紧凑图位，无图时显示通用订阅标识。读取中保持图位稳定，读取失败保留状态文字和既有说明入口。封面尺寸是视觉上限，图片读取、抽样和资源约束沿用既有链路。[封面读取状态](../../../app/src/main/java/com/cooper/lithic/feature/media/CoverPreviews.kt)

底部主要动作占实测高度，正文滚动区域在其上方终止。未提供主要操作的状态让正文获得剩余高度。顶部操作及底部主按钮独立预留至少 48×48dp 触控面积，避免窄窗口或大字下「返回」「更多」「说明」出现相邻命中重叠。原两个详情已有独立滚动正文和页尾操作，导航外壳使用 `WindowInsets.safeDrawing`。金额、续费、结束与纠错表单继续按 `C2FormScaffold` 的 IME 间距和已测量提交区处理。[项目详情](../../../app/src/main/java/com/cooper/lithic/feature/project/ProjectDetailScreen.kt) · [订阅详情](../../../app/src/main/java/com/cooper/lithic/feature/subscription/SubscriptionDetailScreen.kt) · [页面外壳](../../../app/src/main/java/com/cooper/lithic/app/LithicNavigation.kt) · [表单布局](../../../app/src/main/java/com/cooper/lithic/core/design/C2Page.kt)

长金额依次让位给单列、全宽。保持系统设定的字号，不截断数字、符号、单位、日期或状态。极端值保留原完整金额入口、横向查看与复制。现有 `MoneyMetric` 内部会按宽度尝试较小字级，若下一阶段全宽仍触发这一路径，应将「保留详情字号并启用完整值查看」作为限定详情的实施项验证，不能据画板声称已有行为满足。原始金额、精度及格式化规则继续由现有组件提供。[金额语义与完整值操作](../../../app/src/main/java/com/cooper/lithic/core/design/MoneyMetric.kt) · [现有字级策略](../../../app/src/main/java/com/cooper/lithic/core/design/AmountLayout.kt)

## TalkBack、键盘与触控

- 顶部返回沿现有来源命名，例如「返回订阅列表」。更多用「更多项目操作」或「更多订阅操作」。每个详情标题及主要分组有标题语义。阅读顺序从身份、成本、金额事实到逐笔记录，随后为资料或管理入口。照片有独立动作时用可辨动作名称，通用图标不重复读出名称或状态。
- 项目金额节点朗读指标名称、人民币数值、正负方向及每天单位。订阅分别读出「历史平均日成本」「当前标准日均价」「累计已确认实际付款」。付款条目依次读实际付款日、金额、覆盖区间、周期和状态，再到该笔纠错入口。项目的非现金折抵与订阅已付尚未生效均有明确文字。真实零值、未取得、旧快照、读取失败或封面失败应可通过朗读区分。
- 主操作、信息、封面状态、重读、继续加载及按条纠错各自为焦点目标。静态事实行使用普通读序。图表可通过既有日期输入、选中日期和值、显示点和记录入口取得同一事实，触屏手势只是补充。刷新或继续加载结果播报应稳定，避免焦点跳离用户正在核对的记录。[现有图表页面](../../../app/src/main/java/com/cooper/lithic/core/design/CostChartPage.kt)
- 弹窗先读名称及后果，再到取消与确认动作。结束、删除、暂停和停止分别保留已有影响说明。保留关闭更多菜单或底部面板后的返回路径，检查已展开面板的系统 Back、预测 Back 与页内返回。未保存可继续编辑或明确放弃。待核对写入与恢复锁定仍由现有导航守卫处理，焦点应回到核对或原操作。[现有返回和写入守卫](../../../app/src/main/java/com/cooper/lithic/app/LithicNavigation.kt)
- 三主题靠文字和层级说明普通、停止、错误、负金额和待核对。静态颜色不能代表最终对比度。原生验收测量常规文本至少 4.5:1、大文本和关键信息边界至少 3:1，并覆盖系统栏叠层、焦点、图表和真实模态。浅分隔线仅辅助分组。

## Android 后续验收

| 场景 | 需要核实的证据 | 当前 |
| --- | --- | --- |
| 实际系统字体与 360／400／720dp | 系统设置、Activity 读数和原生截图。100%／200% 分别检查长中文、极端金额、状态、付款区间、日期、页尾和触控坐标。 | NOT_RUN |
| TalkBack 与键盘焦点 | 逐项确认币种、符号、单位、非现金、未来覆盖及旧快照朗读。验证关闭菜单／对话框后焦点和分页位置。 | NOT_RUN |
| 窗口与 Insets | 核对三键、手势导航、横竖屏、分屏、状态栏、缺口和 IME。滚动到末笔，检查底部主要动作、最后的风险提示和校验字段。 | NOT_RUN |
| 返回与确认保护 | 复核无改动、草稿、提交中、待核对、已提交但重读失败、恢复锁定。确认系统 Back 和页内返回均走既有守卫。 | NOT_RUN |
| 主题与照片 | 取三主题原生状态对照。验证横图、竖图、无图、读取中和失败，复测深色与错误叠层对比度。 | NOT_RUN |

检查以画板、布局测量和源码证据为限。若真实 200% 发生关键信息裁切、金额无法完整访问、确认动作越过守卫或焦点困在模态，停止该项验收并保存对应截图、读数和操作路径。
