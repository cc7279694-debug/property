## 视觉定稿建议

成本移回品牌栏下方，金额、单位、截止日期和「非今日扣款」集中展示。项目档案按原预览顺序排成连续条目，照片与名称、类别、状态、持有时间和单件日均在同一行组内。订阅沿用对齐关系，保留自己的成本口径。页尾的已录入数量与成本构成供按需查看。

| R2 私人物档 | R2.1 |
| --- | --- |
| 大幅项目照片占据首段，账本成本在首条项目后 | 首屏先读全账本金额，每张封面回到所属项目的档案行 |
| 首条用大图，第二条与无照片时的行节奏待定 | 同尺寸的档案行可承接两条预览，缺图用类型图标 |
| 主题差异主要由全页底色和文字色形成 | 岩白雾蓝用浅雾蓝页首和通栏分界衔接暖白档案面，纯白以较重的黑色金额与内缩细线组织，深色黑灰用略亮的连续页首与炭黑内容面拉开层次 |
| 主要评审有记录的常态 | 补足无封面、多条项目、仅历史、空账本、两种读取失败及大字长名称 |

**推荐 4:3 的 80 × 60dp 显示框。** 相同宽度下，16:9 只有 45dp 高，横向照片更省空间，但竖图完整放入后主体偏小。4:3 多出 15dp 高度，在连续行里仍能辨认物品。样稿使用等比完整适配，竖图两侧保留底色，横图也按原比例放入。标题可换行，大字时金额下移成独立一行，封面保持小幅。实际照片读取、存储和资源引用沿原路径。

**照片来源**为 Hexafluoride 拍摄的 *Kindle 4th Generation*。从 2841 × 1728 等比缩至 947 × 576，保留完整画面，导出的 JPG 无原始 EXIF。画板使用合成账本，照片仅示意条目已经关联封面时的排版。产品条目仍以自身关联封面为来源。照片及画板内的照片复制沿用原许可。[原照片](https://commons.wikimedia.org/wiki/File:Kindle_4th_Generation.jpg) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) · [画板用照片](mockups/reader-photo.jpg)

## 状态检查

| 样稿 | 展示依据 |
| --- | --- |
| 无封面、多条项目 | 未设置封面时显示项目类型图标，行文沿用相同对齐。已关联而无法读取的封面保留原有「封面暂不可用」语义和状态说明入口。 |
| 仅有历史 | 有记录且两类当前有效数量都为 0，样例的账本日均为 `¥0.00/天`，提示暂无当前有效记录，保留含历史数量及原入口。 |
| 确认空账本 | 快照确认无记录且没有读取告警。金额为「—」，两项计数均为 0，保留添加引导，省略预览与成本构成。 |
| 读取失败，保留快照 | 数字、数量和日期沿用上次结果，明确标注其时效，保留原重试路径。保留的预览也须有可用旧数据。 |
| 读取失败，无快照 | 金额与数量使用「—」，日期无来源时省略。保留读取提示和重试，避免推断账本为空。 |
| 大字与长名称 | 320dp 等效窄屏的浏览器模拟。名称自然换行，金额及单位整体重排，滚动时保留新增和主导航。 |

生产还区分读取中、日期更新中和已确认无当前预览。全局账本重试与项目/订阅预览重试保留各自的范围，读取告警期间的空快照继续等待确认。真实负值或零值沿金额组件呈现。[账本重试与导航](../../../app/src/main/java/com/cooper/lithic/app/LithicNavigation.kt#L419) · [汇总状态](../../../app/src/main/java/com/cooper/lithic/feature/home/HomeOverviewPresentation.kt) · [预览和空态条件](../../../app/src/main/java/com/cooper/lithic/feature/home/C2HomePresentation.kt) · [封面读取状态](../../../app/src/main/java/com/cooper/lithic/feature/media/CoverPreviews.kt)
