## 每批交付证据

- 用固定基线报告生产差异和保护文件证明。直接比较已冻结的首页与底栏画面或像素，通过后续对应运行回归覆盖跨入口影响。
- 同一批的代表页面采集纯白、岩白雾蓝、深色黑灰的原生画面，覆盖 320／360／400dp、100%／200%、长文、键盘、滚动终点、48dp 目标和读屏。仅有桌面或浏览器时登记 `NOT_RUN`。
- 每一个金额、日期、状态、守卫或写入入口用现有测试合同对应，增加只针对差异的回归。原生真机操作和安装需要明确的设备授权。记录实际运行数量、失败、不确定和未运行项。
- R0 的六张高保真 PNG 与参数表用于审查和验收对照。R0 的交付不授予正式实施、APK 构建或合并权限。
