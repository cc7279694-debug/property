## 落地锚点

- B2 手机页横边距 16dp、记录卡圆角 14dp 和 1dp 细描边提供砺石自身参照。原分段的 48dp 触控与内层 Ripple 裁切可作为其他分段的验证样例。[B2 首页实现](../../../app/src/main/java/com/cooper/lithic/feature/home/HomeShell.kt#L424) · [R1 验证证据](../../evidence/LITHIC-UI-V4-B2-SEGMENT-PRESS-REPAIR-01.md)
- 原三主题通过 `lithicColorScheme` 和 `LocalLithicVisuals` 提供背景、表面、文字、分隔及状态色。将阴影和卡面依赖降至组级别，在深色主题里优先以表面层差表达分组。[主题角色](../../../app/src/main/java/com/cooper/lithic/core/design/LithicTheme.kt#L30) · [既有色板](../../../app/src/main/java/com/cooper/lithic/core/design/LithicVisuals.kt#L17)
- 砺石详情采用冻结层级，保留财务明细、近期记录、完整记录访问及订阅或项目对应的主操作。独立的回看和成本趋势使用已录入的日期与成本口径。[项目详情](../../../app/src/main/java/com/cooper/lithic/feature/project/ProjectDetailScreen.kt#L209) · [订阅详情](../../../app/src/main/java/com/cooper/lithic/feature/subscription/SubscriptionDetailScreen.kt#L115) · [回看说明](../../../app/src/main/java/com/cooper/lithic/feature/review/ReviewShell.kt#L65)
