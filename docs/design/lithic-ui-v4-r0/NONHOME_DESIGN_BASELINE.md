## 逐组实施约束

### 回看与分析

- **回看首页**保留趋势摘要、全历史、分析与历史档案。趋势是第一个数据区，入口采用分组行。确认空账本时走原空态与「去首页记录」。其它状态继续显示各自的口径、报错、重试和已取得结果。
- **成本趋势**以快照和现有有效点判定展示。至少两个不同日期有效点时才绘制趋势，保留总额和项目折线、订阅分项阶梯，以及负值尺度、选日和分项开关。只有一个有效日期时改用紧凑事实块，显示真实选中日、总额和分项，维持原范围工具、选日结果、文本点清单及事件入口。零点、确认空、已取得的零、未取得、读取失败或旧快照分别表现。后续实现先核对对照组单日期「存在」与「显示点精简」的区别，防止用缩略点数量误判数据基数。[趋势生产实现](../../../app/src/main/java/com/cooper/lithic/feature/review/TotalCostTrendScreen.kt)
- **年度回顾**先呈现所选年及项目净投入、订阅实际付款两个具名值，随后是项目投入和收回、分类构成、已取得的年度趋势、相关记录。按原币种及实际资金日期，展示非现金折抵口径、年度负值与缺失年份。跨年比较继续采用同一有符号尺度和当前分类归属。不构造年度总支出，空年份未知与真实零分别处理。
- **长期复盘**使用一个领域分段、一个排序区。项目保留陪伴时间最长和日均成本最低两种排序，订阅保留折算付费时长。长期项目与订阅的指标名、可排名数量、实际排名、不可排名原因、详情来源与分页均跟随真实模型。
- **类别分析**采用同一日期／构成和状态系统。项目与订阅分别表达，不为统一画板而合并金额，保留观测日与历史事实。

### 列表、详情、表单和设置

- **项目／订阅列表及历史**首层为记录名称和事实状态，第二层为日期、原价或成本。保留当前列表／历史定位、数量、原排序、继续加载和返回来源。终点提示适合短行，报错时显示原旧数据提示。无照片支持既有身份占位。
- **项目详情**沿用封面与身份、日均成本与累计投入双卡、默认收起的财务明细、最近三笔金额记录与「全部」、更多资料、固定「记一笔」的顺序。封面原行为、未确认写入、图片错误、结束项目及危险操作资格照常。**订阅详情**按原服务身份、历史平均日成本、当前／下一期等计划状态、最近三笔付款与「全部」、已存在的管理区和主操作呈现。继续采用已冻结的信息结构与各自支付、日期和保留历史语义。
- **创建／编辑**遵循原字段顺序、原提交方式及校验优先级。日期或类别摘要提供清晰的标签和当前值，展开仍走原日期输入或选择路径。项目初始实际投入为 0 与留空保留区别。表单底部操作仅在相同业务资格下启用，错误能滚回所属字段。长金额、超长名称、横屏 IME、返回及未确认写入是必验状态。
- **设置与备份**把外观、记录管理、提醒提示、备份与恢复、照片统计、说明与关于分别放在浅分组下。导出、只查与覆盖分别保留原动作与结果，恢复仍先预览再确认，照片管理仅在现有实现中具备的能力。主题和时区沿用原读取来源及设置约束。
