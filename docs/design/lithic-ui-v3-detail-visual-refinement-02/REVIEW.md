## 与两张双屏参考的差异

- **照片及服务形象**。参考中的品牌相机与醒目蓝色云图标改用合成相机和中性通用图标。约 2:1 的横幅以 Fit 完整显示原图，在两侧留出中性色。实际产品仍展示记录已有封面。
- **金额及日期**。参考的金额只体现字号与对齐。画板使用 V3-03 的合成样本，在当前套餐和历史中保留付款日与覆盖边界的区别。千分位仅为画板排版，实际产品沿用现有金额格式化。
- **记录入口**。「全部」沿用参考的轻量文字和箭头。浏览器画板打开同一组记录的只读视图。Android 实施时需先确认如何在现有详情内展开完整记录，成本历史继续走原入口。订阅仅当确有更多结果时提供继续加载。
- **底部捷径**。用户附图主按钮下的三图标捷径按对话附件的精简结构省去。编辑、成本历史、以旧换新、订阅管理等沿用已存在的菜单或行入口。系统返回及原有详情导航范围由现有路由决定。
- **状态及装饰**。日期、持有或订阅状态均保留文字。多色记录圆点、日历及叠层装饰从主要读数周围移除，信息入口仍可取得统计口径。参考中分隔、卡片与底部动作的相对位置沿用。

## 响应与操作保护

360／400dp 下以文字可换行为先。200% 时财务卡由三列改纵排，金额、单位、截止和覆盖日期按可用宽度重排，极端金额保留完整值访问。滚动区域测量到固定按钮之前，独立操作目标至少 48dp。金额与状态有可读语义，不靠颜色说明。返回、表单未保存、待核对结果、结束和永久删除、照片操作失败、旧快照与未取得数据均按现有合同。暂停、恢复、停止只影响砺石记录，服务商自动续费需在服务商处操作。当前无有效套餐时保持原语义，已确认的日均贡献零可以显示，未知值与旧快照区别呈现。[状态与写入保护](../lithic-ui-v3-03-details/BUSINESS_FACTS_AND_GUARDS.md) · [无障碍验收边界](../lithic-ui-v3-03-details/ACCESSIBILITY_RESPONSIVE.md)
